TR: NotexTodoApp, Flutter kullanılarak geliştirilmiş bir not ve yapılacaklar listesi uygulamasıdır. Bu uygulama, kullanıcıların notlarını ve görevlerini kolayca yönetmelerine yardımcı olmayı amaçlamaktadır.

#Özellikler
- **Not Ekleme ve Düzenleme: Kullanıcılar, metin tabanlı notlar oluşturabilir ve mevcut notlarını düzenleyebilirler.**
- **Görev Yönetimi: Yapılacaklar listesi oluşturarak görevlerinizi takip edebilirsiniz.**

- **Kurulum**
- **1-)Flutter Kurulumu:**
- **Cihazınızda Flutter SDK'nın yüklü olduğundan emin olun. Kurulum için Flutter resmi dokümantasyonunu takip edebilirsiniz.**

- **2-)Depoyu Klonlayın:**
 - **git clone https://github.com/umitalbayrakk/NotexTodoApp.git**
- **3-) Bağımlılıkları Yükleyin:**

- **cd NotexTodoApp**
- **flutter pub get**
- **4-)Uygulamayı Çalıştırın:**
- **flutter run**
- **Herhangi bir sorunuz veya öneriniz varsa, lütfen umitalbayrakk ile GitHub üzerinden iletişime geçin.**

EN: NotexTodoApp is a Flutter-based application designed to manage notes and to-do lists with ease. It provides a seamless way to organize your tasks and reminders.

Add and Edit Notes: Create text-based notes and edit existing ones.
Task Management: Keep track of your tasks with a dedicated to-do list feature.
